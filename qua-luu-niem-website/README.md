# Dự án phát triển website của hàng quà lưu niệm
Đây là một dự án nhằm góp phần *tối ưu hóa* **quảng bá sản phẩm** ***lưu niệm tại địa phương***
---

| Thư mục | Nội dung |
| --- | --- |
| logs | chứa nội dung dự án |
| data | lưu trữ các dữ liệu dự án |
| media | lưu trữ các hình ảnh, mặt hàng |
---
Câu lệnh liệt kê nội dung toàn bộ dự án
```Powershell
ls -Force
```
---
- [x] Lên ý tưởng, nội dung cho dự án
- [] Tạo website cho dự án
---
> "*Lưu ý không được đăng tải hay xóa file .env lên bất cứ trang mạng xã hội nào*"
